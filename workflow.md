# Flujo de trabajo en Git y GitHub

## Pasos:
1. Crear un repositorio en GitHub.
2. Configurar las ramas principales:
   - `main`: Rama principal del proyecto.
   - `dev`: Rama para desarrollo y pruebas.
3. Realizar cambios en la rama `dev`:
   - Agregar o modificar archivos.
   - Hacer commits para guardar los cambios.
4. Hacer un **pull request** para fusionar `dev` con `main`.
5. Revisar los cambios y aprobar el merge.

## Notas:
- Usar mensajes de commit descriptivos para facilitar el seguimiento de cambios.
- Mantener la rama `main` limpia y funcional.
